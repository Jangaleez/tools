# Tools

Free, home-grown tools by [Jangaleez](https://github.com/Jangaleez). Each folder is a separate tool with its own instructions.

| Tool | What it is | Runs on |
|---|---|---|
| [PC Care Kit](pc-care-kit/) | A tabbed app for PC health and maintenance: startup apps, cleanup, disk space, updates and repairs | Windows 11 (no install needed) |
| [Screen Recorder & Editor](screen-recorder/) | Record the screen, then trim, cut, speed up, rotate or join videos | Windows, using Python + FFmpeg |

## Downloading a single tool

You don't need Git. Open the tool's folder above, click each file, then click the **download** button (↓) at the top right of the file view. Keep all of a tool's files in the same folder.

To get everything at once, use the green **Code** button → **Download ZIP**.
