COLD KEY GENERATOR - OFFLINE INSTRUCTIONS
=========================================

1. Start the computer from your Tails USB stick.
2. On the Tails Welcome Screen, open Additional Settings (the "+" button, or Alt+A),
   turn on "Offline Mode", then click Start Tails.
3. Plug in the USB stick that holds this folder.
4. Open the folder in Files, right-click an empty space > "Open in Terminal".
5. Type:   bash start.sh    and press Enter.

The generator checks everything first (no network, bundle unchanged, Bitcoin Core
signatures, self-test against published test values) and stops if anything is wrong.

Before you start, have: paper, a pen, and nobody (and no camera) able to see the screen.

When you're finished, shut Tails down - that wipes everything from memory.
Never type your seed phrase into a computer or phone that goes online.
